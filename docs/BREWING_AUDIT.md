# 酿药机制核对记录

本记录区分代码核对、自动回归验证与游戏画面对照。2026-10-01 用户撤回游戏启动与交互授权，后续仅只读检查本地代码/资源及联网查询。此前启动游戏后窗口截图超时，未获得有效画面对照，不能标记为实测通过。

## 本轮修正与证据

| 机制 | 代码/资源证据 | 实验台处理 |
|---|---|---|
| 倒液后保留路径 | `RecipeMapManager.MoveIndicatorTowardsObject` 设置药瓶位置；路径位于药瓶容器下，未调用 ResetPath | 按药瓶位移平移剩余路径，再按倒液造成的朝向变化旋转；路径长度保持 |
| 日/月盐旋转已有路径 | `PathMapItem.OnIndicatorAngleChanged` 与 `FixedHint.RotateBy` 更新已投放路径点 | 绕当前药瓶旋转全部剩余路径 |
| 盐的旋转方向 | `SaltSun/SaltMoon.OnCauldronDissolve` 调用 `IndicatorRotationSubManager.RotateBy`，其计算为 Value - byDegree | 太阳盐顺时针、月亮盐逆时针；每单位约 0.36° |
| 旋转后加入新药材 | `NonTeleportationNonFixedHint.SetIngredientPath` 从原药材路径重建，并以最后一段路径末端为位移起点 | 新药材按自身坐标方向追加，不继承药瓶倾角 |
| 部分搅拌后可继续操作 | `NonTeleportationFixedHint.RunAlongPath` 消耗路径前段；其他操作各自更新地图状态 | 剩余路径作为持久状态，继续接药材、倒液、投盐、加热 |
| 倒液速度和旋转 | `GetSpeedOfMovingTowardsBase`、`MoveIndicatorTowardsObject` 与 Pouring/Indicator Settings | 持续时间和强度控制倒液，移植速度曲线、持续倒液加速及每单位移动旋转上限；按 1/60 秒积分 |
| 生命盐 | 资源 `Life Salt.healthToAdd = 0.004000000189989805` | 每单位恢复约 0.4%，不消耗路径 |
| 虚无盐 | 资源 `Void Salt.lengthToErase = 0.009999999776482582`，`PathEraserController` 擦除末端 | 每单位从剩余路径末端擦除约 0.01 单位 |
| 加热收集药效 | `RecipeMapManager.CollectEffect` 与 `PotionManager.ApplyEffectToPotion` | 保留路径；依照五个效果槽与采集顺序更新药效；同地图已采集点标记不可再采集 |

上述文件位于 `reference/decompiled/` 下。基础数值来自 `data/` 中的资产，不采用反编译类字段的默认值替代实例值。

## 2026-10-01 重连后：晶体状态与数值

已完成路径段元数据，并启用全部九种晶体的实验模拟。普通路径与晶体路径分别记录；倒液、日/月盐与虚无盐保持段类型。传送完成后，后接路径保持原来的世界坐标，本次搅拌结束，下一次搅拌才继续后续段。GUI 用紫色点线区分晶体路径，导出的 `teleports` 包含三个阶段的逐帧位置、半径、生命值、接触区与模拟步长。

证据来自 `TeleportationFixedHint.RunAlongPath/UpdateMovingAlongPathStatus`、`TeleportationAnimator`、`IndicatorMapItem.UpdateHealth`、`DangerZonePart.GetHpChange` 及实例参数：

- 传送沿 graphics 采样路径前进；实例 graphics 与 physics 间距均为 `0.05000000074505806`。
- 速度为 `20 + 0.4000000059604645 × 8 × 搅拌强度`；当前一次操作采用强度 1。热量乘子曲线恒为 1。
- 淡出/淡入名义时间各 `0.30000001192092896` 秒，实际进度速度按传送速度除以 20 缩放。
- 淡出完成后碰撞体切到 layer 0，淡入开始回到 layer 8。安装资源的碰撞矩阵禁止 layer 0 与地图区 layer 8 碰撞，因此穿越途中没有危险区/沼泽触发，但基液回血逻辑仍运行。
- 淡出/淡入的强区损伤系数各 `0.6000000238418579`，弱区各 `0.20000000298023224`，乘以动画状态增量。碰撞体随缩放曲线缩小，放大超过 1 时半径封顶原尺寸。
- 完成帧 `IsAnimating` 已置 false，淡变损伤计算不再生效；当前实现保留这一分支，接触区采用即时几何查询。
- Unity 固定步长从 `globalgamemanagers` 导出为 `705599/141120000 ≈ 0.004999992914` 秒。它不是渲染帧时间。当前传送显式采用 `1/60` 秒的近似渲染步长，不能据此断言与原游戏损伤一致。

数值数据新增 `data/unity_simulation_settings.json`，保存 TimeManager、Physics2DSettings、PhysicsManager、TagManager 原始设置。动画曲线求值已支持带权贝塞尔切线。

23 项回归检查通过，新增覆盖九晶体三种研磨程度、连续晶体、晶体后接普通药材、旋转与倒液后传送、虚无盐修改落点、穿越危险区/沼泽和危险区落点损伤。浏览器实际操作验证了 CloudCrystal 后接 Waterbloom：第一次搅拌后落点 `(0.003, 1.574)`、剩余路径 `3.241` 单位，后接普通路径仍保留。这是实验台的运行验证，不是游戏实测。

### 贤者之盐的批次操作

`SaltPhilosophers.OnCauldronDissolve` 每次加入一个寿命为 1 的独立粒子；`RecipeMapManager.MoveIndicatorByPhilosophersSalt` 每帧按 `deltaTime / 0.10000000149011612` 消耗其寿命，累加移动预算 `0.02250000089406967` 和最大旋转预算 `0.36000001430511475°`。朝最近未采集药效移动并调整朝向；移动与旋转预算均受沼泽倍率 `0.6777777671813965` 影响；到达精确位置和朝向时清空剩余盐寿命，不返还盐。它清零本帧搅拌行进量，但不擦除剩余路径。

已开放“同时溶解并等待”的批次操作。整批共享开始时刻，采用 1/60 秒近似帧，不能代表真实逐粒投放、与搅拌/倒液/加热同时作用或完整 tween 时序。新增四项测试核对单位移动预算、中心处旋转预算、跳过已采集药效、到达后不越过目标、路径保留与沼泽倍率；当前共 **27 项**通过。

浏览器验证：在上面的晶体落点加入 10 单位贤者之盐，药瓶移动至 `(0.134, 1.391)`，距最近药效从 `9.112` 降至 `8.887`，剩余路径仍为 `3.241`。截图保存为 `docs/crystal-salt-verification.png`。

### 边界进一步核对

`KillOutOfMap` 检查的是地图背景矩形的 `Rect.Contains`，不是力场多边形。力场另外通过 `PolygonCollider2D.ClosestPoint` 修正目标点：修正距离为多边形外距离减药瓶半径及 `distanceToFailPotion`（实例为 0）；修正距离大于药瓶半径时失败。源码在搅拌路径移动中跳过传送期力场修正，且沼泽分支先于力场分支。此处记录的是上一轮尚未实现的情况；下节记录本轮接入与验证。

## 2026-10-01：目标朝向、动画朝向与等级判定

本轮只读分析了 `RecipeMapManager.IndicatorRotationSubManager`、`PathMapItem.OnIndicatorAngleChanged`，并从本机 `PotionCraft.Core.dll` 单独反编译 `FloatExtension`。没有启动游戏或执行游戏程序集中的代码。

- `Value` 是目标朝向；`RotateTo` 立即更新它。`VisualValue` 是动画朝向，通过线性 DOTween 逐帧靠近目标，更新瓶子 Transform，并发出 `onAngleChanged(previous,new)`。
- `RotateBy` 按目标朝向 `Value - byDegree` 累积，然后重新启动从当前动画朝向到新目标的旋转。因此连续盐粒会重启动画，不能只用一个朝向变量描述中途状态。
- 原始资源中日/月之盐单粒角度分别为 `0.36000001430511475`、`-0.36000001430511475` 度；旋转动画时间均为 `0.05000000074505806` 秒。参数经 `RotateBy` 的减号后，月盐正向、日盐反向。
- 药效等级判定 `GetEffectTier` 使用 `indicatorRotation.Value`，而不是 `VisualValue`。剩余路径旋转来自动画朝向的 `onAngleChanged`；这两个作用时间不同。
- `FloatExtension.Is(value,target)` 调用 `Abs(value-target) < Mathf.Epsilon`。三级的 `num3.Is(1f)` 不提供常见的百分比容差；需要钳制后的单精度分数等于 1。不能把它误读为宽松的约等于判定。当前引擎用双精度计算并要求分数达到 1，单精度中间舍入尚需核对。

默认旋转动作仍按原先的完整旋转语义执行。新增 `deferred=true` 日/月盐动作将目标朝向、动画朝向、未结束 Tween 起点/进度/持续时间分别入状态；药效评分读目标，剩余路径随动画回调旋转。等待、搅拌、鼓风、晶体动画的时间推进控制器；倒液切换旋转方式时取消未结束动画。**尚未证明 Unity 组件执行顺序、晶体与旋转同时作用的轨迹和真实盐粒抵达时序被精确复现**，不能把同时溶解批次推广为完整实际输入模型。

`engine/rotation.py` 的单精度控制器已接入 `PotionSession`、GUI 调度器、状态保存恢复和优化器回放。GUI 的“日/月之盐保留旋转动画”选项可观察中途状态。新增六项会话验证覆盖剩余路径半程旋转、期间加料、目标角评分、状态恢复、状态键区别和晶体期间时间推进；连同三个控制器源码对照用例，全套 60 项检查通过。尚未用新的时序动作完成全部目标搜索。
