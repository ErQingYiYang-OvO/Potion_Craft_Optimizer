# 搜索运行快照

新接入快照的运行会在候选文件的 `runs[].snapshot` 中记录压缩包路径、包校验值、Python/NumPy 版本。压缩包保存启动时的引擎、优化器、测试、提取数据、共享 GUI 调度器、依赖清单、模型计划，以及已有结果和候选/容错检查点；同内容复用一个包。较早的原型包未包含结果检查点，仅适用于引擎回放，不能直接重跑依赖成本上界的求解器。

需要重跑时，在本项目下新建一个独立恢复目录，将该包解压到那里，核对 `RUN_SNAPSHOT.json` 中每个文件的 SHA-256；按记录的依赖版本配置运行环境，再使用该运行记录的基液、药效、盐网格、停点、等待时间和迭代预算。参数与快照都应匹配。完整操作配方也可直接载入实验台复核。

包不含游戏安装程序集、图片资产或 Python/NumPy 安装包。它保存当前模拟模型，不代表已经完全还原原游戏。

此前未记录快照的运行仍保留旧指纹和操作文件；不能声称已追溯恢复它们运行时的全部代码。不要用当前文件快照替代旧运行版本。
